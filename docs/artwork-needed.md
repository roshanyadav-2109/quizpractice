# Icons needed

One line-art icon per branch, exam and subject, with a colour splash behind it, and no blue. They replace the grey notebook placeholder in the navbar menus, on the home page subject cards and on each subject page.

## Palette

| Colour | Hex | Used for |
|---|---|---|
| Charcoal | `#292524` | The line drawing, one even line weight |
| Coral | `#EE6C4D` | The one key detail per icon, named in each description |
| Saffron | `#F4B942` | Splash colour (each icon gets one) |
| Sage | `#9CCB8F` | Splash colour (each icon gets one) |
| Lilac | `#C9B3E6` | Splash colour (each icon gets one) |
| Rose | `#F6B2C3` | Splash colour (each icon gets one) |
| Lime | `#D5E26A` | Splash colour (each icon gets one) |

Splash shapes rotate through: a rounded blob, a single diagonal dry-brush stroke, a torn-paper patch, an ink splash with a few scattered droplets, a crescent-shaped wash, a rough hand-painted circle. No tile, circle or block behind the icon; the background is transparent.

## How to make them

Paste one sheet prompt at a time into the same chat. Send me the sheets as they come: I will cut them up, make the white background transparent, and name the files.
